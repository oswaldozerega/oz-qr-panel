# OZ QR Code Generator · panel

Interfaz del panel privado de OZ QR Code Generator. **Este repositorio no contiene datos**:
el panel se muestra dentro de la página privada `oswaldozerega.com/ozqrcodegenerator` (solo
miembros administradores) y todos los datos viajan por esa página hacia el backend de Wix,
que verifica el permiso de administrador en cada operación.

Publicado con GitHub Pages desde la rama `main`.
