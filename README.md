# OZ QR Code Generator · panel

Interfaz del panel privado de OZ QR Code Generator (v0.2.0). **Este repositorio no contiene datos**:
el panel se muestra dentro de la página "OZ QR Code Generator" del panel de control de Wix de
oswaldozerega.com, y todos los datos viajan por esa página hacia el backend de Wix, que verifica
el permiso de administrador en cada operación. Abierto fuera de Wix, el panel no carga nada.

Publicado con GitHub Pages desde la rama `main`.
